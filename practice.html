🎯 এই প্ল্যাটফর্ম সম্পর্কে

ICT Practice Platform হল HSC শিক্ষার্থীদের জন্য একটি বিশেষ কোডিং প্র্যাকটিস পরিবেশ। এখানে তোমরা HTML এবং C প্রোগ্রামিং সরাসরি ব্রাউজারে প্র্যাকটিস করতে পারবে। কোনো সফটওয়্যার ইন্সটল করতে হবে না।

📌 HTML গুরুত্বপূর্ণ পয়েন্ট

• HTML মানে HyperText Markup Language
• প্রতিটি ট্যাগের Opening ও Closing থাকে। যেমন: <p>...</p>
• Self-closing tags: <br>, <img>, <input>
• Attribute: id, class, src, href, type ইত্যাদি
• colspan ও rowspan দিয়ে টেবিল cell merge করা যায়

📌 C প্রোগ্রামিং গুরুত্বপূর্ণ পয়েন্ট

• প্রতিটি statement এর শেষে semicolon (;) দিতে হয়
• scanf() এ variable এর আগে & দিতে হয়
• int: পূর্ণসংখ্যা, float: দশমিক, char: অক্ষর
• printf() এ \n দিয়ে নতুন লাইনে যাওয়া যায়
• for(init; condition; update) — লুপের গঠন

⌨️ কীবোর্ড শর্টকাট

• Tab — ইন্ডেন্ট করো
• Ctrl+A — সব কোড সিলেক্ট
• Ctrl+C / Ctrl+V — কপি/পেস্ট
• Ctrl+Z — পূর্বাবস্থায় ফিরে যাও
• Enter — নতুন লাইন

🔤 Format Specifier (C)

• %d — int (পূর্ণসংখ্যা)
• %f — float (দশমিক)
• %c — char (একটি অক্ষর)
• %s — string (অক্ষর সারি)
• %lf — double
• %o — Octal, %x — Hexadecimal
